# Director de membri

Site static + Supabase. Fara framework, fara build.

- `docs/`                 site-ul, servit de GitHub Pages
- `supabase/migrations/`  schema bazei de date, se ruleaza in SQL Editor
- `supabase/functions/`   functii server (inscriere, ping)
- `scripts/`              reimprospatarea lunara a bazei de referinta

Datele (CSV, exporturi) nu intra niciodata in repo. Vezi `.gitignore`.
